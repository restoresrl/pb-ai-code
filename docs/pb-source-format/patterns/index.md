# Cross-cutting patterns

This folder collects structural blocks that appear in multiple entry
types — so they can be documented once and cross-linked from each
page that uses them.

Examples of patterns that will live here once seeded:

- `forward` block — forward type declarations at file top.
- `type variables` block — instance variables of a class.
- `event` block — event definition syntax (and `on …` shorthand).
- `function` body inside a `type` block — member function syntax.
- `global type … from …` — the top-level type declaration.
- `end type` terminators — placement rules and pitfalls.

This folder is currently empty. Pages will be added the first time
a pattern is documented in any entry-type page deeply enough to be
worth extracting.
